# Portfolio OS

An AI-powered interactive portfolio built with Next.js, TypeScript, Tailwind CSS, Framer Motion, GSAP, Three.js, and modern web technologies.

## Tech Stack

- Next.js 16
- TypeScript
- Tailwind CSS
- Framer Motion
- GSAP
- Three.js
- React Three Fiber
- Lenis
